Simulador de lanzamiento de dados

Aplicación de consola en Python que simula el lanzamiento de distintos tipos de dados (D4, D6, D8, D10, D12 y D20), con una animación del lanzamiento y resultados coloreados usando la librería rich.

Uso
1.Elige 1 para lanzar dados.
2.Selecciona el tipo de dado (D4 a D20).
3.Indica cuántos dados quieres lanzar (máximo 5).
4.Verás una breve animación y, después, el resultado de cada dado junto con el total y el promedio de la tirada.
5.Elige 2 para salir del programa.

Características
Menú principal en bucle.
Validación de entradas (texto no numérico, cantidades fuera de rango).
Animación del lanzamiento con Live y Panel de rich.
Resultados coloreados: verde (valor máximo), rojo (1), amarillo (resto).
Cálculo automático del total y el promedio de la tirada.
